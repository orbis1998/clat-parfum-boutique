# Éclat Parfum Boutique

Je veux un website e-commerce pro avec un design pro, typographie pro que tu auras à proposer, avec le commande qui redirection sur whatsapp, le site devrait être shopify mais sans moyen de payement incluse. L'architecture du site doit être comme ceci : admin gestion de tout le site, livreur, gérant. l'admin voit tout gérer tout sauf rien, celui qui créé les comptes des livreurs, gérant. la configuration du site doit être accueil, panier, connexion, articles. Et ici j'aimerais que tu clones un thème shopify qui vend les parfums, la section héro doit être pro avec un effet balayage de produit, et la page connexion ne doit pas avoir le bouton créer, il n'y a que les personnels qui peuvent se connecter avec id : ( badge ) et mot que l'admin aura à créer.  A ce niveau tu crée tout sans liaison avec une base de donnée, donc tout ici créent les mockété.  tout doit être configurer dans le panel admin, ajout de produit, les variantes, la gestion finance, la fincance, les articles, etc... même le numéro qui doit redirection la commande sur whatsapp doit être configurer chez l'admin. Le chekout doit avoir l'atircle avec tout les details, le nom compte, l'adresse, instruction, date et jour de la livraison, au niveau de la commune, mets les 2
